# Ashewa Electronics — Premium Storefront Concept

A lightweight, responsive static storefront concept designed for Ashewa Electronics and ready for Cloudflare Pages.

## Stack
- Single static `index.html`
- No build step
- No server required
- Responsive CSS + lightweight vanilla interactions
- External CTA links to Ashewa's Telegram channel and Ashewa.com

## Deploy to Cloudflare Pages
1. Open Cloudflare Pages.
2. Create a project from this GitHub repository.
3. Framework preset: **None**.
4. Build command: leave empty.
5. Output directory: `/`.
6. Deploy.

## Notes
This is a visual/demo storefront concept. Product availability, prices, phone numbers, addresses, payment methods, and official brand assets should be verified with Ashewa before production launch.

## Research basis
The concept uses publicly visible Ashewa messaging around electronics categories, easy ordering, fast delivery, quality guarantees, friendly support, and free delivery above 5,000 ETB. The Telegram CTA points to the public Ashewa Electronics channel.
